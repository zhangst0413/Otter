# pi-sdk

## 在终端中使用pi

安装pi：`npm install -g --ignore-scripts @earendil-works/pi-coding-agent`

pi还依赖fd和ripgrep，它们能提升文件和代码块的查找

安装fd：`winget install -e --id sharkdp.fd`

安装ripgrep: `winget install BurntSushi.ripgrep.MSVC`

使用：在目标目录下执行`pi`并回车即可启动，然后输入`/login`添加模型供应商。另外可使用`/model`切换模型，使用`/thinking`切换思考强度
